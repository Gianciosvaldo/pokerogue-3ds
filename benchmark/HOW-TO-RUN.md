# Running the PokeRogue benchmark on your 3DS

1. Copy `pokerogue-bench.3dsx` to your SD card, in the `3ds` folder (`sd:/3ds/pokerogue-bench.3dsx`).
2. Put the SD card back, open the Homebrew Launcher and start **PokeRogue benchmark**.
   - Best: open the Homebrew Launcher through a game (title takeover: hold **R** while starting any game, or use Rosalina's "Homebrew Launcher" entry). That gives the app the full 64 MB. If it crashes or freezes at startup, this is the first thing to try.
3. Wait. The bottom screen says "Running..."; the top screen prints one line per battle turn. Expect a few minutes (about 1.5 minutes in an emulator, probably longer on the real console). Don't press HOME while it runs.
4. When the bottom screen says **Done**, press **START** to exit.
5. Send back the file `sd:/3ds/pokerogue-bench-result.txt` (paste its contents in the thread). A photo of the top screen's SUMMARY lines also works.

Nothing is installed or saved except that one result file. The app contains no Pokemon sprites or music, only game code, English text and a few small data tables. It is a personal build; don't share it.
