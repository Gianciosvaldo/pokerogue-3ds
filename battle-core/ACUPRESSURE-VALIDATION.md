# Acupressure callback and owning turns

Base: merge `e74a9abaf2d32d96f746c62f63069eb03940037d` (Helping Hand, #285).
Reference: upstream `8555c08c823b856cbec4eb99ca84ea52a955836d`, locales
`270ed0a2938b2c3e2e34e7de940e84aecadf548b`, Node 22.23.3.

The pinned `AcupressureStatStageChangeAttr.apply` filters `BATTLE_STATS` in
ATK/DEF/SPATK/SPDEF/SPD/ACC/EVA order using the target's stages below six. If
any remain, it selects with the user's battle RNG and queues a +2
`StatStageChangePhase` for the target, with the user as `sourcePokemon`.
It does not call the parent HP, condition or chance gates. No eligible stats
means no phase and no RNG draw. The C callback follows that override and uses
the existing shared stat phase for ability multipliers, bounds and messages.

## Actual source observations

`tests/acupressure.producer.test.ts` captures the original BattleScene battle
RNG method **before** constructing GameManager and restores it after startup.
It calls the real registered attribute, without replacing any gameplay method.
Only phase advancement is stalled to inspect the queue.

The 16,384 complete API cases include all 128 capped-stat subsets, self/ally/
opponent positions on both sides, living/fainted actors, stages -6/0/4/5/6,
and move arguments with different secondary-effect chances. The C replay
matches all 16,256 queued phases, marker placement and level counts, dynamic
queue emptiness/contents, target/source ownership, amount and self-target
metadata, unchanged actors and both RNG streams. Zero mismatches.

Ten compiled Acupressure faults are caught: absent handler, added HP or chance gate,
including capped stats, omitting evasion, reversed stat order, global RNG,
wrong source, wrong target and wrong amount. Eighteen malformed captures are
rejected. A +1 instead of +2 fault also causes 30 covered full-turn failures
in the plain seed777 sample, demonstrating actual stat-phase execution.

Three fresh unchanged broad doubles captures each write all 2,000 requested
turns with zero source exceptions, parse or initial-stat mismatches:

| Sample | Covered before | Covered after | Gained IDs | Lost IDs |
| --- | ---: | ---: | ---: | ---: |
| Plain seed777 | 1,850 | 1,888 | 38 | 0 |
| Rich seed777 | 1,852 | 1,884 | 32 | 0 |
| Plain seed2034 | 1,859 | 1,889 | 30 | 0 |

All 5,661 covered turns and their exact localized messages match. ID sets,
rather than net counts alone, establish no loss. The existing chooser,
exclusions, comparator and breadth requirements are unchanged. There are
still 339 explicitly unsupported turns among these 6,000 observations.

The dedicated full-turn matrix is generated by
`tools/build-acupressure-turn-proof.py` from a copy of that unchanged driver.
It adds explicit ordinary species, capped-stat masks, native Simple/Contrary
and +5 clipping contexts, self/ally target selection and occasional Surf/
Explosion controls. It retains the real turn phases, both RNG streams,
complete state/text comparison and the existing doubles breadth assertions.
Its validation command requires all 8,194 turns to be covered. The final two
turns add explicit two-opponent Hyper Voice targeting controls; the first
8,192 matrix cases are retained.

The initial 8,192-turn capture exposed one existing false-positive form marker:
reserve Meloetta reached the post-move dispatcher without a Relic Song history.
The native registration cannot trigger in that situation. A narrow predicate
guard removes that false marker; it does not implement Relic Song transitions.
All 8,192 original turns now compare exactly. Thirty-two direct native no-op
predicate controls match, eight positive transitions remain explicitly
unsupported, and removing the guard causes 32 direct failures. Together with
the ten Acupressure faults, eleven compiled faults are detected. Random reserve
species, including the original Meloetta case, remain in the owning matrix.

Four retained mixed seed777 fixtures (plain/rich/summon/switch, 8,000 total)
retain every covered ID; their covered counts are respectively 1,971→1,971,
1,963→1,965, 1,987→1,991 and 1,989→1,989, with zero compared mismatches.

## Host and merge gates

The additive singles command/save fixture executes the real Acupressure fight
command after a legal save/load, comparing the original/restored runs' stages
and all three RNG states. Nine NONE/Simple/Contrary and uncapped/+5/+6
contexts pass 123 checks. This is a host consistency fixture, not a natural
app doubles run or an upstream save comparison.

The full game-core suite passes; paired 200-run saved/unsaved digests are both
`d42eb77a`. The normal app/custom/save suite and exact-head host/app/3DS CI
remain merge gates; results are recorded in the pull request. The dedicated
custom-only Task63 check remains excluded, with ordinary custom/save tests
enabled. No existing producer, comparator, seed/count or exclusion is relaxed.

## Limits and continuation

The API matrix uses ordinary non-fused actors without held items, statuses or
abilities. The dedicated turn matrix adds Simple/Contrary and the rich sample
adds other native contexts; these bounded captures do not prove every possible
interaction or whole battle-core completion. Core Enforcer/Gastro Acid
suppression, After You, attention redirection and other doubles callbacks,
app/run doubles, broader partners/saves and wide-level Endless remain open.
No run-core edits or emulator/hardware acceptance are included.
