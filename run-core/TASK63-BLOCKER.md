## Authorized partial repair and remaining producer boundary

The user subsequently requested fixing the failure. The C defect is now fixed
inside run-core/src/pokemongen.c: form_index accepts the active RNG explicitly.
pr_run_enemy_pokemon_base_rng passes its supplied temporary stream, while normal
enemy/fusion/public form callers keep passing run->rng. Previously daily.c used
a temporary offset-0 RNG for ability/ID/gender/nature but form_index consumed the
outer run RNG instead. Paldean Tauros therefore shifted its own nature and the
third starter, and previews mutated the caller's RNG.

A separate host regression tests the public daily API's outer-RNG preservation,
repeatable previews and the pinned first daily starter sequence. It adds a
Makefile target without editing any existing producer or comparison. It passes
27/27 checks with the repair; the same executable built against the original
library fails five checks (exit 1).

The producer also has an independent input defect. Upstream's pinned
test/helpers/classic-mode-helper.ts runToSummon normalizes IVs to 31 and nature
to Hardy and disables shinies. daily.producer.test.ts initializes through that
helper and never clears the player overrides. BattleScene.addPlayerPokemon
then overwrites the real daily IVs and nature when assembling Starter records.
The C comparator correctly still checks those fields. Changing C to reproduce
test-only overrides would break natural daily generation.

An external diagnostic copy of the producer clears just those three overrides
after setup. Original library against that natural-input trace: **773 passing
checks / 2 mismatches, exit 1**. Repaired library against the identical trace:
**775 passing checks / 0 mismatches, exit 0**. Repaired library against the
original normalized-input trace: **760 passing checks / 15 mismatches, exit 1**.
No failed established result is counted as passing.

The original producer-edit prohibition is still respected. The following
input-only patch is proposed for review, not applied to the repository:

```diff
   vi.spyOn(activeOverrides, "DISABLE_STANDARD_TRAINERS_OVERRIDE", "get").mockReturnValue(false);
+  // Restore natural player inputs after classic setup normalizes the fixtures.
+  vi.spyOn(activeOverrides, "IVS_OVERRIDE", "get").mockReturnValue(null);
+  vi.spyOn(activeOverrides, "NATURE_OVERRIDE", "get").mockReturnValue(null);
+  vi.spyOn(activeOverrides, "SHINY_OVERRIDE", "get").mockReturnValue(null);
```

This preserves all five daily seeds, 50 waves per seed, comparison fields,
tolerances and the existing moveset snapshot boundary. Permission to edit this
existing producer is needed before claiming the established daily check repaired.
